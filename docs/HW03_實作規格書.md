### 3.2 第一步：`useCrimeData.js` 產生的資料結構

由 `src/composables/useCrimeData.js` 從**原始 CSV** 計算，每個縣市一筆：

```js
{
  id: '新北市', en: 'New Taipei City', region: '北部', isSixCity: true,
  pop: 4045910,
  全般: { count: 111182, rate: 2748.01, clearance: 73.31, rankCount: 1, rankRate: 3 },
  暴力: { count: 57, rate: 1.41, clearance: 98.25, rankCount: .., rankRate: .., ciLow: .., ciHigh: .., smallN: false },
  竊盜: { count: 13584, rate: 335.75, clearance: 74.72, rankCount: .., rankRate: .. }
}
```

另附 `meta`：各案類的犯罪率中位數、破獲率中位數、資料來源說明。

### 3.3 清理規則（一定要遵守）

1. **CSV 有 BOM**，用 `encoding='utf-8-sig'`。
2. **細項表（04、06）的空白或 JSON null ＝ 0 件**，轉成 0。
3. **破獲率空白 ≠ 0**：連江縣暴力犯罪 0 件，破獲率無法計算，存成 `null`。畫面顯示「—（無案件）」。
4. **人口不在原始資料中**：以 `發生數 ÷ 犯罪率 × 100,000` 反推，取全般刑案計算。畫面一律標「推估人口」，不可寫「常住人口」。
5. **排名**：由大到小，1 為最高。目前資料犯罪率無並列；件數只有暴力犯罪有 3 組並列，並列時採同名次（competition ranking，例如 1, 2, 2, 4）。
6. **95% 區間**：用精確 Poisson 區間（Garwood），在 `utils/stats.js` 以 Poisson 累積機率加二分搜尋實作（件數 ≤ 64，計算量很小）；不要再用常態近似）。0 件時下限為 0。
7. **smallN**：暴力犯罪件數 < 30 為 true。
8. 縣市加總 ≠ 全國（全般 600,909 vs 608,717），**不要用縣市加總當全國值**。全國值從 `01_表1` 的 2025 列取。

## 5. 互動與狀態

### 5.1 狀態物件

```js
state = {
	crimeType: '全般', // '全般' | '暴力' | '竊盜'
	barMode: 'count', // 'count' | 'rate'（只影響圖表 A）
	filter: 'all', // 'all' | 'six' | 'nonSix'
	hovered: null, // 縣市 id
	pinned: null, // 縣市 id
}
```

狀態放在 `useViewState.js`（Vue `reactive`），各元件讀取並透過它提供的函式修改，元件之間不直接呼叫。D3 只負責繪圖與轉場，DOM 由 D3 在各元件的 `<svg ref>` 內管理。

### 5.2 規則

1. **高亮優先順序**：`pinned` > `hovered`。有 pinned 時，hover 只顯示 Tooltip，不改變高亮。
2. **點擊**縣市：設為 pinned；再點同一縣市或點空白處、按 Esc：取消。
3. **篩選**：不符合的縣市**變淡（透明度 0.15），不隱藏**。
4. **排名與中位數永遠用全國 22 縣市**，不因篩選重算。畫面標示「全國名次」。
5. 切換案類時保留 pinned。
6. 發現卡點擊＝一次設定 crimeType、barMode、filter、pinned。

### 5.3 Tooltip 內容

```
花蓮縣（東部・非六都）
```

## 6. 發現卡（初版文案，數字已核對）

1. **件數第 1 不等於最危險**：新北件數全國第 1，換算每十萬人後是第 3；花蓮件數第 17，犯罪率卻是全國第 1。→ 全般、rate 模式、pin 花蓮。
2. **六都換算後仍偏高**：六都犯罪率都在全國前 9 名，但破獲率也都高於中位數。→ 全般、filter six、散佈圖。
3. **暴力犯罪最高的縣，只有 8 件**：澎湖暴力犯罪率全台最高（7.46），但只有 8 件，95% 區間很寬，排名不可靠。→ 暴力、rate、pin 澎湖。
4. **破獲率可以超過 100%**：暴力犯罪有 6 縣市超過 100%，因為破獲數含往年積案。→ 暴力、散佈圖。

文字用「可能」「顯示」，不寫因果。不要寫「觀光人口造成」之類未驗證的原因。

## 7. 統計限制（頁尾固定顯示）

- 資料：內政部警政署《警政統計年報》2025 年（民國 114 年）。
- 自 2024 年 9 月起，部分刑案由「1 案 1 發生數」改為「1 被害人 1 發生數」；2025 全年皆為新制，本頁不做跨年比較。
- 破獲數含破積案，破獲率可能超過 100%。
- 犯罪率以戶籍人口計算，不含在當地活動但未設籍的人口（不寫「觀光」等未驗證的原因）。
- 警察紀錄不含未報案犯罪；數字是描述性差異，不代表個人風險。
