# 前端設計方向：「更正單」

> 2026-11-10 定案｜依據：`frontend-design`、`design-taste-frontend`、`uiux-design-system` 三個 skill 的分析，與目前版面的檢討。
> 與 `.claude/rules/` 衝突時以專案規則為準。

## 一、主題、讀者與任務

- **主題**：同一份 2025 年警政資料，用件數排和用每十萬人犯罪率排，縣市名次差多少。
- **讀者**：一般民眾與查核記者；評分者是視覺化課程老師（重視 Munzner 原則、不誤導）。
- **頁面的主要任務**：讓讀者親眼看到「名次被更正」。

## 二、概念

把整頁當成一張「排名更正單」：原報導的件數排名是被更正的草稿，每十萬人犯罪率是更正後的版本。全頁只有一個記憶點——**圖表 A 切到犯罪率時，每一列的舊名次被畫上刪除線，旁邊寫上新名次**（例如 ~~17~~ → 1）。其他元素保持安靜、克制。

## 三、Token

### 顏色（每個顏色只代表一件事）

| 名稱 | 色碼 | 只用於 |
| :-- | :-- | :-- |
| 霧灰紙 | `#EEF2F1` | 頁面背景 |
| 圖紙 | `#FBFCFC` | 圖表區底色 |
| 墨 | `#1C2A2E` | 文字、軸線、被選取的故事、鍵盤焦點框 |
| 石板 | `#55646B` | 次要文字（對比 5.4:1） |
| 淡石板 | `#5F6E74` | 圖說、註解（對比 4.7:1，14px 以上） |
| 件數灰 | `#7F8C92` | 件數模式的橫條（「待更正」的量） |
| 率青 | `#0E6F7A` | 每十萬人犯罪率：橫條、散佈點、地圖色階深端 |
| 螢光黃 | `#F4C542` | 被選取縣市的底色帶，**不當文字色** |
| 線 | `#CBD5D6` | 1px 邊框與分隔線 |

- 拿掉原本的米白 `#F7F6F2`（接近 AI 預設的紙張色）、橘色強調色，以及散佈圖的五色區域色（沒有任何任務需要區域色；區域改在 Tooltip 與資料表呈現）。
- 地圖色階：`#E3EEEF` → `#0E6F7A`（與率青同一色相，表示同一個量）；格內文字依底色明度自動切換墨色或白色。

### 字型

- **Noto Serif TC 700**：只用在頁面標題與故事標題，帶出「公文／更正單」的語氣。
- **Noto Sans TC 400／500／700**：其他所有文字；數字一律 `tabular-nums`（不使用等寬字型）。
- 字級：14（圖說、註解下限）／15（控制項）／16（內文）／18（圖表標題、故事標題）／40（頁面標題）。

### 形狀

- 圓角只有一種：6px（圖紙、分段控制項、故事帶）。不再使用膠囊形按鈕。
- 不使用陰影；層級靠 1px 線與底色區分。唯一例外：控制列貼頂時加細線與柔和陰影（使用者要求，2026-11-10）。

- 內容區置中（最大寬度 1260px，等於圖表 B＋C 並排加左右邊距）；區內文字一律靠左對齊。
- 控制列（含原本在圖表 A 裡的「件數／每十萬人」切換）合併成一列，捲動時固定在頂端，並附一行目前狀態，截圖時也帶著脈絡。
- 每張圖的關鍵提醒移到該圖下方；頁尾保留完整版。

## 五、原則

1. 記憶點只有一個：名次更正（刪除線＋新名次）。
2. 一個顏色一個意思：率青＝犯罪率，件數灰＝件數，螢光黃＝選取，墨＝文字與目前狀態。
3. 選取時只淡化圖形，文字維持可讀（淡化後對比不低於 3:1）。
4. 動畫只用在「件數 ↔ 犯罪率」重排與案類切換；尊重系統的「減少動態效果」設定。
5. 不加編號標籤（「發現 1」）、不加「→」、不用全大寫英文標籤、不用「A・B・C」式的資訊串。

## 六、自我檢討（避免 AI 範本感）

| 檢查 | 結果 |
| :-- | :-- |
| 米白底＋襯線大標＋陶土橘？ | 底色改霧灰青、強調色是率青與螢光黃，非此組合 |
| 每段內容都切成一樣的圓角卡片＋陰影？ | 故事改為一條分段帶；圖表區無陰影 |
| 小型數據標籤用等寬字？ | 改用 Sans 的 tabular-nums |
| 編號標籤、「→」、全大寫眉標？ | 全部移除 |
| 記憶點是否來自主題本身？ | 是：「名次被更正」就是本作業的核心發現 |

## 七、實作步驟

- **第 11 步（頁面層級）**：Token、字型、標題、故事帶、固定控制列（含排序切換與目前狀態）、圖紙樣式。
- **第 12 步（資訊架構與版面，2026-11-10 追加）**：第一列 A＋C 並排、第二列 B 全寬；排序依據移到圖 A（只影響 A），預設每十萬人犯罪率；控制列只留案類與篩選並註明套用到三張圖；狀態列顯示懸停／鎖定縣市摘要；每張圖標題改為資料算出的一句結論。
- **第 13 步（圖表層級）**：A 的更正名次與件數灰／率青橫條；B 改單色點並移除區域圖例；C 改率青色階與文字對比；選取時文字不淡化；統計提醒移到圖下；減少動態效果。
