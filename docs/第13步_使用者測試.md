## 困惑與可能誤會

| 位置 | 問題 |
| :-- | :-- |
| 圖 A 刪除線 | 以為是「資料錯了被更正」 |
| ▲▼ | ▲ 看起來像「進步」，其實是犯罪率名次變高 |
| 淡色 ▲▼ | 以為是不能按的按鈕；說明在圖下方 |
| 件數排序 | 橫條變灰、格式變「1（3）」，以為圖被停用 |
| 黃色 | 懸停與鎖定都是黃色，分不出來 |
| 暴力犯罪圖 A | 多個縣市「件數第 17」（並列名次），以為資料錯 |
| 圖 C 灰底、Y 軸到 120% | 看到超過 100% 以為算錯 |
| 圖 B 斜線格 | 以為是沒有資料 |
| 圖 C 標題 | 標題提到基隆市，但圖上沒有標它的名字 |
| 用語 | 中位數、95% 信賴區間、Poisson、等積方塊地圖、推估人口 |
| 價值判斷 | 圖 B 顏色深像「越危險」；「不代表個人風險」只在頁尾，第一時間會以為花蓮最危險 |

## 測試者建議的 3 件事

1. 圖 A 名次直接寫文字，▲▼ 說清楚意思。
2. 「不代表個人風險」等提醒放到首屏。
3. 懸停與鎖定用不同樣式；件數模式橫條不要變灰。
