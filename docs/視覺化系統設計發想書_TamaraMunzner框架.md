## 3. Tamara Munzner 四層巢狀模型深度拆解

Munzner 提出的 **Four-Level Nested Model** 是視覺化設計的最高指導原則。任何一層出錯，視覺化系統都會失效：

```text
+-------------------------------------------------------------------+
|  Level 1: Domain Situation (領域問題：搞清楚誰要用、有什麼痛點)     |
|    +-------------------------------------------------------------+
|    |  Level 2: Data & Task Abstraction (抽象化：轉為 What 與 Why)  |
|    |    +-------------------------------------------------------+
|    |    |  Level 3: Visual Encoding & Interaction (設計：How)     |
|    |    |    +-------------------------------------------------+
|    |    |    |  Level 4: Algorithm & Implementation (演算法實作) |
+----+----+----+----+---------------------------------------------+
```

---

### Level 1: 領域情境與核心痛點 (Domain Situation)

- **領域問題**：公共安全感受（Public Perception of Crime）被傳統媒體的「絕對案件數排名」嚴重曲解。
- **認知失調**：民眾看到新聞報導「破獲率 100%」，卻感受不到治安變好；看到六都案件上萬，便誤以為都會區危機四伏。
- **評估驗證威脅**：錯誤的問題定義會導致做出的圖表「只是官方統計年報的另一種死板翻版」，使用者依然無法解惑。

---

### Level 2: 資料與任務抽象化 (Data & Task Abstraction)

#### 📊 What（資料型態抽象化）

- **Dataset Types**：
  - **Table（屬性表）**：22 縣市（Items） × 22 欄治安指標（Attributes）。
  - **Geometry（地理幾何）**：22 縣市邊界的空間向量多邊形（Spatial Polygons）。
- **Attribute Types & Ordering**：
  - `機關別_中文`：Categorical（類別）。
  - `區域`（北部、中部、南部、東部、離島）：Categorical。
  - `是否六都`：Categorical（二元分類：是 / 否）。
  - `全般/暴力/竊盜發生數_件`：Quantitative, Ratio（具備真實零點的絕對計數）。
  - `每十萬人犯罪率`：Quantitative, Continuous（人口常態化連續指標）。
  - `破獲率_百分比`：Quantitative, Continuous（績效指標，值域 $[0, 100+]$）。
- **Derived Attributes（關鍵衍生屬性）**：
  - `總數排名 (Rank_Count)`：依發生件數遞減排序（1 ~ 22）。
  - `犯罪率排名 (Rank_Rate)`：依每十萬人犯罪率遞減排序（1 ~ 22）。
  - `排名位移值 (Rank_Delta = Rank_Count - Rank_Rate)`：定量呈現「人口校正後的反轉震撼度」。

#### 🎯 Why（任務抽象化：Action + Target）

依據 Munzner 的 Task Taxonomy：

1. **Analyze ➔ Consume ➔ Discover & Present**：
   - **Discover**：探勘各縣市在全般、暴力、竊盜三種維度下的異常點（Outliers，例如花蓮人均犯罪率飆高、連江暴力為 0）。
   - **Present**：向大眾揭示「總量」與「率」的巨大排序分歧。
2. **Search ➔ Lookup & Browse**：
   - **Lookup**：已知目標縣市（例如居住在花蓮或新北），查找其在四象限散佈圖中的具體落點。
   - **Browse**：瀏覽全台地圖，觀察高犯罪率是否存在「東部/西部或城鄉差距的空間叢聚（Spatial Clustering）」。
3. **Query ➔ Compare & Identify**：
   - **Compare**：橫向對比「六都內部」的破獲率與犯罪率（如台北 82% vs 新北 73%）。
   - **Identify**：找出破獲率突破 100% 的特殊縣市，並呈現其背後的「破積案」背景。（2025 全般刑案沒有縣市超過 100%，最高是嘉義縣 91.34%；超過 100% 的只出現在**暴力犯罪**：雲林 114.29%、新竹市 112.5%、金門 110%、基隆 107.14%、彰化 106.67%、南投 105%）

### Level 3: 視覺編碼與互動慣用手法 (Visual Encoding & Interaction: How)

#### 🎨 Visual Encoding (視覺編碼原則)

Munzner 提出的通道有效性定律（Channel Effectiveness）：**空間位置（Position on common scale）永遠是最強大的量化通道，長度（Length）次之，再次為色彩飽和度/明度。**

1. **空間位置通道（Position on Common Scale）**：
   - 散佈圖使用 X 軸（犯罪率）與 Y 軸（破獲率），讓定量數值的對比具備最高精確度。
2. **長度通道（Length）**：
   - 橫條圖以水平長度代表數值大小，且共用左側基準線（Aligned Length），便於人眼快速掃描 rank 差異。
3. **色彩明度通道（Color Luminance / Saturation）**：
   - 地圖面量圖使用單色循序色票（Sequential Palette, 如 Blues），**嚴禁使用 Rainbow Colormap**，確保色盲無障礙（WCAG 相容）。
4. **色彩色調通道（Color Hue）**：
   - 用於區分 5 大分區（北藍、中橘、南綠、東紫、離島灰）或六都二元類別，限制在 5 色以內，防止色彩過載。

#### 🕹️ Rules of Thumb（實務防坑準則）

- **Eyes beat memory（眼見勝於記憶）**：同時並置（Juxtapose）散佈圖與地圖，讓使用者不必切換頁面記憶數值。
- **Overview first, zoom and filter, then details-on-demand（先宏觀、再過濾、後細節）**：
  - 預設先看全台宏觀鳥瞰 ➔ 提供六都/非六都過濾按鈕 ➔ 滑鼠懸停顯示卡片級 Tooltip。
- **No unjustified 3D / No decorative clutter**：全站採純二維平面投影，無任何擬 3D 陰影柱，確保數據傳遞純淨。

### Level 4: 演算法與工程驗證 (Algorithm & Validation)

- **D3 Scale Selection**：
  - 散佈圖與長條圖：`d3.scaleLinear().domain([0, d3.max(...)]).nice()`
  - 地圖色彩映射：`d3.scaleSequential(d3.interpolateBlues)`
  - 類別上色：`d3.scaleOrdinal(d3.schemeTableau10)`
- **Geo Projection**：
  - 台灣地理投影：`d3.geoMercator().center([120.9605, 23.6978]).scale(7000)`
- **Transitions & Timing**：
  - 動畫時間控制在 600ms ~ 800ms，搭配 `d3.easeCubicOut`，防止動畫過慢造成視覺疲勞。

### 圖表 C：空間雙軌對照地圖 —— 地理真實 vs. 等積方塊蜂巢圖 (Meta-Visualization)

- **核心哲學（Meta-Visualization）**：**用視覺化批判視覺化自身的面積偏誤（Area-Size Bias）！**
- **雙模式一鍵無縫切換機制**：
  在圖表右上角提供膠囊切換鈕：`[ 🗺️ 真實地理邊界 (Geographic) ] ⇄ [ ⊞ 等積蜂巢方塊 (Equal-Area Tile Map) ]`。
- **模式 1：傳統真實地理面量圖（Geographic Map, BOCSAR Style）**：
  - **視覺呈現**：還原台灣 22 縣市真實國土輪廓，外島（連江、金門、澎湖）以左上角圓角微縮卡片（Inset Map）呈現。

- **模式 2：等積蜂巢方塊地圖（Equal-Area Tile Grid Map, OWID/NYT Style）**：
  - **視覺呈現**：將全台 22 縣市化為 **1:1 完全等大的正方形/六角形網格**，依據地理相對方位（北、中、南、東、離島）排列。

    1. **徹底消除土地面積霸凌人口**：花蓮縣與臺北市佔據的像素面積一模一樣大，視覺權重完全公平。

- **切換時的教育性批判標籤（Pedagogical Callout）**：
  > 💡 **視覺化深度省思：為什麼需要「等積方塊地圖」？**

## 5. CMV 協同多重視圖架構與深度互動機制 (CMV & Interaction Design)

### 5.1 CMV 協同通訊架構 (Event Dispatcher Bus)

在 D3.js 實作中，四張圖表不直接硬編碼耦合，而是透過 `d3.dispatch` 進行狀態廣播：

```javascript
// 全域 CMV 事件匯流排
const dispatcher = d3.dispatch('countyHover', 'countyLeave', 'countySelect', 'metricChange')

// 視圖 A (地圖) 發出廣播
countyPaths.on('mouseover', (event, d) => {
	dispatcher.call('countyHover', null, d.properties.name)
})

// 視圖 B (散佈圖) 監聽並響應
dispatcher.on('countyHover.scatter', (countyName) => {
	scatterDots
		.classed('highlighted', (d) => d.機關別_中文 === countyName)
		.classed('dimmed', (d) => d.機關別_中文 !== countyName)
})

// 視圖 C (橫條圖) 監聽並自動捲動高亮
dispatcher.on('countyHover.bar', (countyName) => {
	barRects.classed('highlighted', (d) => d.機關別_中文 === countyName)
})

// 視圖 D (案類 DNA) 監聽並重新繪製結構組成
dispatcher.on('countySelect.dna', (countyName) => {
	renderCrimeDNA(countyName)
})
```
